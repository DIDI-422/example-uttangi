# 💌 우땅이의 따뜻한 편지 카드 (Uttangi Cute Card)

귀여운 **우땅이** 배경 이미지와 함께 따뜻한 손글씨 편지, 은은한 꽃잎·반짝이 효과, 그리고 오르골 멜로디를 감상할 수 있는 반응형 웹 카드 프로젝트입니다.

---

## 📁 폴더 및 파일 구성

```text
uttangi_card/
├── index.html     # 메인 웹 카드 페이지 (HTML, CSS, JS 통합)
├── uttangi.png    # 전체 배경으로 사용되는 우땅이 이미지
└── README.md      # 프로젝트 안내 문서
```

---

## ✨ 주요 기능

1. **풀스크린 배경 & 따뜻한 색감**
   - `uttangi.png`를 화면 전체 배경으로 배치하고, 햇살이 비치는 듯한 포근한 반투명 오버레이를 더했습니다.
   - 모바일 세로 화면에서도 상단의 우땅이 얼굴이 가려지지 않도록 배경 위치와 카드 여백이 자동 조정됩니다.

2. **위에서 아래로 내려오는 편지 애니메이션**
   - 귀여운 손글씨 폰트(`Gaegu`, `Jua`)를 적용해 제목부터 본문 각 줄, 서명까지 순차적으로 부드럽게 내려오며 나타납니다.
   - 하단의 **`✨ 편지 다시 읽기`** 버튼을 누르면 언제든 애니메이션을 처음부터 다시 재생할 수 있습니다.

3. **은은한 꽃잎 & 반짝이 파티클 효과**
   - HTML5 Canvas를 활용해 5잎 작은 꽃송이가 바람에 살랑이며 떨어지고, 배경 곳곳에서 4각 별빛 반짝이가 은은하게 빛납니다.

4. **별도 음원 파일 없는 오르골 멜로디 (`🎵 음악 켜기`)**
   - Web Audio API를 이용해 브라우저 자체에서 맑은 오르골 음색의 귀여운 멜로디를 실시간으로 연주합니다.
   - 우측 상단의 **`🎵 음악 켜기 / 🎶 음악 끄기`** 버튼으로 간편하게 켜고 끌 수 있습니다.

---

## 🚀 실행 및 사용 방법

1. 압축을 푼 폴더(`uttangi_card`) 안에 `index.html`과 `uttangi.png`가 같은 위치에 있는지 확인합니다.
2. `index.html` 파일을 더블클릭하여 웹 브라우저(Chrome, Safari, Edge 등)에서 엽니다.
3. 우측 상단의 **`🎵 음악 켜기`** 버튼을 눌러 오르골 멜로디와 함께 편지를 감상합니다.

---

## 🎨 커스터마이징 팁

- **편지 내용 수정하기:** `index.html` 파일에서 `<h1 class="letter-title">`, `<p class="line">`, `<p class="letter-sign">` 태그 안의 텍스트를 원하는 문구로 변경하면 됩니다.
- **배경 이미지 교체하기:** 같은 폴더에 새 이미지를 넣고 `index.html` 내 `.bg-wrapper`의 `background-image: url('./uttangi.png');` 경로를 수정해 주세요.
